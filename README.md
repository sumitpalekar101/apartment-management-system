\# Apartment Visitor Management System



A Django-based web application to manage visitors and visitor passes in an apartment.



\## Technologies Used

\- Python

\- Django

\- MySQL

\- HTML, CSS, JavaScript

\- Bootstrap



\## Features

\- User login and authentication

\- Visitor registration and management

\- Visitor pass creation and management

\- Visitor search

\- Reports

\- Profile and password management



\## Installation



1\. Clone the repository.

2\. Create and activate a virtual environment.

3\. Install dependencies:



&#x20;  pip install -r avs/apartment\_visitor\_system/requirements.txt



4\. Create a MySQL database.

5\. Create a `.env` file using `.env.example` as a reference.

6\. Apply migrations:



&#x20;  python manage.py migrate



7\. Start the server:



&#x20;  python manage.py runserver



\## Configuration



Keep your secret key and database password in the local `.env` file. Never upload `.env` to GitHub.
